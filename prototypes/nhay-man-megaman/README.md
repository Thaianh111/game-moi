# Nhảy Màn Kiểu Megaman

Game nhảy màn bắn súng kiểu Megaman.

**Trạng thái:** chưa có code trong repo.

Game này làm trong các cuộc trò chuyện trước với Claude nên file chưa được đưa lên đây.
Muốn cất vào: mở lại cuộc trò chuyện cũ, tải file `.html` của game về, đổi tên thành `index.html`
rồi bỏ vào thư mục này (`prototypes/nhay-man-megaman/`). Khi đó link chơi sẽ là:
https://thaianh111.github.io/game-moi/prototypes/nhay-man-megaman/
